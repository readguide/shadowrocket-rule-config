# Shadowrocket domestic / global domain rules

The four public configurations retain their existing policy groups, service rules and fallbacks. Their broad China/Global RULE-SET references point to this repository's `rules/china.list` and `rules/global.list` mirrors. A daily GitHub Actions workflow refreshes these files, validating syntax and minimum size before committing. A failed fetch or validation leaves the published lists intact. Scheduled runs may be delayed; Shadowrocket must refresh cached rules to use a newer revision.

**Corrected upstream:** [Johnshall/Shadowrocket-ADBlock-Rules-Forever](https://github.com/johnshall/Shadowrocket-ADBlock-Rules-Forever), the maintained successor of h2y. The proxy mirror is generated from its `build/factory/resultant/gfw.list` (CC BY-SA 4.0), not its complete .conf, because importing the latter would overwrite local policy groups, DNS, ad blocking, and fallback behavior. The China mirror continues to use blackmatrix7's maintained China list; Johnshall's `top500_direct.list` is dated 2022 and contains foreign domains, so is unsuitable as an automatically updated China-direct list. This is a **blocked-site proxy list, not a comprehensive all-foreign-domain list**. Existing service-specific rules remain ahead of both broad lists. Blacklist versions preserve `Global.list -> PROXY` and `FINAL,DIRECT`; whitelist versions preserve `FINAL,PROXY`.

Run locally: `python3 scripts/update-domain-rules.py --check` (offline validation), or `python3 scripts/update-domain-rules.py` (refresh sources). No subscription URLs or proxy credentials are included.
